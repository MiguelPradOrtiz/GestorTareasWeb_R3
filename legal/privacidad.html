Aviso de Privacidad

Gestor de Tareas Web - UVEG 2026

1. Finalidad

Gestor de Tareas es una aplicación académica desarrollada para organizar actividades personales en un entorno local de simulación.

2. Datos almacenados

La aplicación almacena las descripciones de las tareas, su estado de cumplimiento y la fecha de creación en una base de datos MySQL.

No solicita nombres, contraseñas, correos electrónicos ni datos de identificación personal. Se recomienda no introducir información sensible en las descripciones de las tareas.

3. Uso de la información

Los datos se utilizan para registrar, consultar, actualizar y eliminar tareas dentro de la aplicación. No se ha implementado una función para compartir información con servicios externos.

4. Medidas de protección

El entorno local utiliza HTTPS con un certificado autofirmado, encabezados HTTP de seguridad, validación de datos en el servidor y consultas SQL parametrizadas.

Estas medidas no garantizan una protección absoluta. La versión académica no cuenta con autenticación de usuarios ni controles individuales de acceso.

5. Conservación y eliminación

Las tareas permanecen almacenadas en MySQL hasta que se eliminan desde la aplicación o se realiza una operación administrativa sobre la base de datos.

6. Alcance

Este aviso describe el funcionamiento de un proyecto académico local. No constituye un aviso de privacidad definitivo para un servicio público.
