Términos y Condiciones

Gestor de Tareas Web - UVEG 2026

1. Descripción del servicio

Gestor de Tareas es una aplicación web desarrollada con fines académicos para organizar y administrar actividades personales.

2. Uso permitido

La aplicación permite registrar, consultar, completar, filtrar y eliminar tareas. Su uso está destinado a demostraciones y pruebas dentro de un entorno local.

3. Responsabilidades del usuario

El usuario debe utilizar la aplicación de manera responsable y evitar introducir información confidencial, datos sensibles o contenido que afecte a terceros.

4. Disponibilidad del servicio

El funcionamiento depende de que los servicios Apache, Express y MySQL estén disponibles. No se garantiza el acceso ininterrumpido a esta versión académica.

5. Limitaciones de responsabilidad

La aplicación se proporciona con fines educativos y de demostración. No se garantiza su disponibilidad permanente ni la ausencia de errores o pérdida de información.

6. Seguridad y privacidad

Se han implementado medidas básicas de seguridad, pero el sistema no cuenta con autenticación ni acceso individual por usuario. No debe utilizarse para almacenar información sensible o crítica.

7. Modificaciones

Las funcionalidades y estas condiciones podrán modificarse conforme avance el desarrollo académico del proyecto.
